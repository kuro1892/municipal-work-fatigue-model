# 付録B：シミュレーションコード（Python）README

## 1. 目的
本フォルダに含まれるコードは、論文  
**「生成AIによる自治体事務支援が職員の疲弊構造に与える影響」**  
における **図2〜図6および表3〜表4** の数値結果を、同一条件下で再現することを目的としている。

本コードは、研究の再現性確保およびパラメータ感度の検討を主眼としており、  
実務システムへの直接的な適用を意図したものではない。

---

## 2. 動作環境
- Python 3.x  
- NumPy  
- Pandas  
- （図を再生成する場合は Matplotlib）

Google Colaboratory 上での実行を想定している。

---

## 3. 評価設計（論文本文・図表と一致）
本コードは、以下の評価定義を**厳密に論文と一致**させている。

- 時間粒度：週次（T = 52）
- 職員数：N = 500
- モンテカルロ反復回数：MC = 1000
- 繁忙期ウィンドウ：weeks 13–31（0-indexed）
- 相対閾値 θ：
  - AI支援なし（None）シナリオについて  
    繁忙期疲弊分布の P90 を **各モンテカルロ反復ごとに算出**
  - それらの **中央値** を相対閾値 θ として採用
- 指標：
  - `mean`：繁忙期ウィンドウ内の「職員×週」プール平均
  - `risk`：同プールにおける Pr(F ≥ θ)
  - `p90` ：同プールの90パーセンタイル

### 5.1 図2〜図5・表3の再現  
（全AI支援シナリオの比較）

```
from_fig2_to_fig5.ipynb

##5.1.1 このコードで行っている分析

本コードは、以下を目的としている。

AI支援 なし（None） を基準とし、

AI支援の種類および組合せ
None, A, B, C, A+B, A+C, B+C, A+B+C

それぞれについて、

平均疲弊（mean）

相対閾値超過確率（risk）

上位分位点（P90）
を 同一条件下で比較する。

この結果が、論文中の 図2〜図5および表1 に対応する。

##5.1.2 疲弊–過誤の連成構造（モデルの考え方）
本モデルでは、次の関係を仮定している。

業務量の増加 → 疲弊が高まる

疲弊の蓄積 → 業務過誤が増える

業務過誤 → さらに疲弊を高める

すなわち、
疲弊と過誤が相互に増幅し合う連成構造を持つ。

##5.1.3 繁忙期ウィンドウでの評価
1年（52週）のうち一部を 繁忙期ウィンドウとして設定

評価指標（mean / risk / P90）は
繁忙期に該当する週のみを切り出して算出

これは、論文本文の評価定義と一致している。

##5.1.4 相対閾値 θ の算出方法
本研究では、疲弊の「危険域」を絶対値で定義しない。

代わりに、

AI支援なし（None）シナリオを MC=1000 回実行

各反復ごとに、繁忙期疲弊分布の P90 を算出

それらの 中央値 を相対閾値 θ とする

という手順で、相対的な基準を構成している。

##5.1.5 生成AI支援タイプの意味
本コードでは、生成AI支援を次の3類型としてモデル化している。

記号	内容	モデル上の作用
A	業務量の削減	外生的業務負荷を低減
B	過誤の抑制	疲弊→過誤の感度を低減
C	疲弊の持ち越し抑制	疲弊の回復・安定化

これらは単独でも、組合せ（A+B 等）でも評価される。

##5.2.1 このコードの位置づけ（重要）

5.2.2 認知特性（λ）の考え方
λ は「疲弊が業務過誤に結びつきやすさ」を表す感度パラメータ

本研究では、

5.2.3 表4の指標について
表4では、

を指標として用いている。

これは、認知特性別の比較において、
水準差そのものを明示することを重視したためである。

5.3 計算時間に関する注意
本コードは、

N = 500

MC = 1000

の設定を用いているため、
実行環境によっては 数分〜十数分程度 の計算時間を要する。

検証目的で短時間実行する場合は、
コード冒頭の MC を小さくして動作確認することが可能である。
